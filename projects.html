A book recommendation system developed as part of my studies. The project focuses on analyzing book rating data and generating personalized book recommendations using an item-based Collaborative Filtering approach. The system identifies books with similar user rating patterns and recommends them based on their similarity.

The application processes book and rating data using Pandas and creates a user-book rating matrix with users as rows and books as columns. Books with fewer than 30 ratings are filtered out to improve the quality of the recommendation data. SciPy Sparse is used to efficiently handle the sparse rating matrix, while Scikit-learn Nearest Neighbors with cosine similarity is used to find the most similar books.

Designed and implemented the data processing pipeline, recommendation algorithm, and Streamlit web application. The application allows users to search for a book, select the desired title from matching results, and receive similar book recommendations displayed with titles, authors, and cover images.

Implemented the application architecture, REST API, authentication and authorization, database integration, frontend components, routing, QR code functionality, data visualization, validation, and automated testing. The application is deployed to the CSC Rahti service and containerized using Docker.
